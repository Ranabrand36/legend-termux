# LEGEND TERMUX

Professional Hacker Style Termux Setup

## Installation

```bash
pkg update && pkg upgrade -y
pkg install git -y
git clone https://github.com/Ranabrand36/legend-termux.git
cd legend-termux
bash install.sh
```

## Features

- Hacker Banner
- Custom Prompt
- User Name
- YouTube Link
- Telegram Link
- GitHub Link
- WhatsApp Channel
- Green Theme
