## 📌 **Overview**

**Legend Termux Banner** ek custom Termux banner installer hai jo aapko apna **personalized hacker-style terminal** banane deta hai.  
Ye tool user se **naam, YouTube channel, GitHub** aur extra message leta hai aur phir **dynamic ASCII art banner** generate karta hai.

> ⚡ **"Apna Termux, Apni Shaan!"**

---

## ✨ **Features**

- 🎨 **Custom ASCII Art** with `figlet` & `lolcat`
- 👤 **User Input** for Name, YouTube, GitHub
- 🔗 **YouTube Channel Link** display
- 🌐 **Live System Info** (IP, Device, Date, Time)
- 💻 **Hacker-Style Prompt**
- 🧼 **Clean & Professional UI**
- 📦 **One-Command Installation**
- 🗑️ **Easy Uninstall**

## 🚀 **Installation**

### **Step 1: Update Termux**
```bash
pkg update && pkg upgrade -y
```

Step 2: Install Git

```bash
pkg install git -y
```

Step 3: Clone Repository

```bash
git clone https://github.com/Ranabrand36/legend-termux.git
```

Step 4: Enter Folder

```bash
cd legend-termux
```

Step 5: Run Installer

```bash
bash install.sh
```

Step 6: Restart Termux

```bash
exit
```

Phir Termux dubara open karein — Custom Banner Ready! 🎉

🗑️ Uninstall

```bash
cd ~
rm -rf legend-termux
rm -rf ~/.bashrc
cp /data/data/com.termux/files/usr/etc/bash.bashrc ~/.bashrc
exit
```

---

🔄 Update Karne Ka Tareeqa

```bash
cd ~
rm -rf legend-termux
git clone https://github.com/Ranabrand36/legend-termux.git
cd legend-termux

exit
```
